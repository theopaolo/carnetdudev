# 📚 Carnet du Dev

A personal coding knowledge base for structured learning and practice.

## 🎯 Purpose

This repository serves as a comprehensive learning system for programming concepts, algorithms, and development practices. It's designed to be:
- **Simple & Flat**: Easy to navigate and maintain
- **Semantic**: Clear organization by topic and difficulty
- **Expandable**: Ready to grow with your learning journey
- **Future-proof**: Can be transformed into a blog/wiki/SSG later

## 📁 Structure

```
carnetdudev/
├── 00_introduction/     # Getting started guides
├── 01_programming-basics/ # Core programming concepts
├── 02_offline-first/    # Offline-first & local-first (IndexedDB, OPFS, CRDT, P2P)
├── 03_theory/          # Software development theory
├── 04_back-end/        # Backend development topics
│   └── orm/            #   ORM, migrations, Merise/UML/ERD (voir 04_back-end/orm/README.md)
├── 05_daily-katas/     # Daily practice exercises
└── meta/               # Project metadata & resources
```

## 🎓 Learning Flow

Each topic includes:
- **notes.md**: Personal explanations and insights
- **flashcards.md**: Quick review questions
- **quiz.md**: Knowledge assessment
- **katas.md**: Practical coding exercises

## 🚀 Getting Started

1. Start with [00_introduction/welcome.md](00_introduction/welcome.md)
2. Read [00_introduction/how-to-use.md](00_introduction/how-to-use.md)
3. Begin with topics that match your current level
4. Use daily katas for consistent practice
